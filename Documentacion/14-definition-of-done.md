# 14 — Definition of Done

Una historia está Done cuando:
- cumple criterios de aceptación;
- código revisado;
- pruebas unitarias/integración relevantes;
- compilación limpia;
- análisis estático limpio según thresholds;
- no existen secretos;
- dependencias revisadas;
- documentación/API actualizada;
- migraciones incluidas si aplica;
- logs no contienen información sensible;
- pruebas de autorización para recursos;
- CI verde;
- evidencia de QA disponible;
- ticket enlazado al PR.
